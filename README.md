# English Language Test Simulator

Android app by HomiLabs for IELTS preparation (Academic and General Training):

- **10 full mock tests** that run like test day: Listening heard once with reading pauses and 2 minutes'
  check time, Reading and Writing on a 60-minute clock, Speaking with timed, recorded answers and a
  1-minute Part 2 preparation.
- **Report** with estimated bands, every Listening/Reading answer explained, transcripts, Band 8 model
  answers, and a self-check for Writing and Speaking.
- **Practice library**: guides and drills for every question type, Writing and Speaking guides with model
  answers, and topic vocabulary.

Content format: `docs/content-schema.md`. Project notes: `CLAUDE.md`.

Independent practice material; not affiliated with IELTS, the British Council, IDP or Cambridge.
